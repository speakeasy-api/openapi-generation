## globals: 0.1.0 - 2026-09-01
### :bee: New Features
- x-speakeasy-cli-commands declarative intent commands — presets, typed inputs, union variants, route dispatch, async polling (--async), artifact outputs, streamed field selection, planned placeholders, catalogs, per-command hints and examples — with strict generation-time linking of every bind, preset and jq projection; declaration-driven artifact content-block and job-identity shapes (output.artifact block/identity field bindings with the prior fixed member names as schema defaults, linked against the response schema so a mismatched binding fails generation instead of silently extracting nothing); declaration-driven async failure-detail bindings (async errorField/errorMessageField with the prior error/message envelope as schema defaults, linked against the poll response schema); x-speakeasy-cli-errors reason-first error classification behind one classifier — agent-mode envelopes by default, and pretty, JSON, TOON and --jq output once cli.classifiedErrors is enabled — with exit codes 0/1/2/3; the --usage, --schema and keyless --dry-run machine interface; explicit interactivity, agent-detection and classifiedErrors policies; declaration-driven reason carriers in x-speakeasy-cli-errors (a reasonPointer primary carrier plus ordered probes with per-carrier rule sets, verbatim reason promotion only for explicitly declared carriers, an unwrapErrorArray normalization for single-element array-wrapped error bodies, and declared account-state types with declared or neutral fallback hints) so vendor error conventions live in the OpenAPI document rather than the generator; cli.defaultTimeout implicit per-operation timeouts with phase-bounded transports and a safe skip-deserialization body lifetime; retry, pagination, server-selection, security-ranking, stdin/--body and output-format fixes; helpStyle, defaultColor, jqRawOutput, retryFlagsVisibility and serverSelectionFlag gen.yaml keys; generated READMEs, command docs and dry-run contract tests derived from the manifest; declared commands named after cobra builtins (e.g. help) are no longer silently dropped, and stream timing tests select the declared toggle flag instead of one literally named stream *(commit by [@ThomasRooney](https://github.com/ThomasRooney))*
