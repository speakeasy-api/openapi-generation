An organization with nested inline schemas in the foo namespace

## Example Usage

```typescript
import { Organization } from "openapi/foo";

let value: Organization = {
  name: "Acme Corp",
  address: {
    street: "123 Main St",
    city: "Springfield",
    location: {
      latitude: 37.7749,
      longitude: -122.4194,
    },
  },
  departments: [
    {
      deptName: "Engineering",
      headCount: 50,
    },
  ],
};
```
