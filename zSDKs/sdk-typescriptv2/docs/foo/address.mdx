Inline address object should end up in foo namespace

## Example Usage

```typescript
import { Address } from "openapi/foo";

let value: Address = {
  street: "123 Main St",
  city: "Springfield",
  location: {
    latitude: 37.7749,
    longitude: -122.4194,
  },
};
```
