Approval configuration with escalation

## Example Usage

```typescript
import { ApprovalConfig } from "openapi";

let value: ApprovalConfig = {
  approvers: [
    "user-1",
    "user-2",
  ],
  escalation: {
    enabled: true,
    expiration: 86400,
    fallbackApprovers: [
      "admin-1",
    ],
  },
};
```
