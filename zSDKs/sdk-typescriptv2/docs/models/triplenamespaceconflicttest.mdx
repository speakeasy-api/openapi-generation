A model that references Pet from foo, bar, and baz namespaces

## Example Usage

```typescript
import { TripleNamespaceConflictTest } from "openapi";

let value: TripleNamespaceConflictTest = {
  fooPet: {
    id: "pet-foo-123",
    name: "Fluffy",
    species: "cat",
  },
  barPet: {
    id: "pet-bar-456",
    name: "Buddy",
    owner: "John Doe",
  },
  bazPet: {
    petId: 789,
    petName: "Rex",
    adoptedAt: new Date("2024-01-15T10:30:00Z"),
  },
};
```
