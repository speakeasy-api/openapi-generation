An array field that contains nested form fields

## Example Usage

```typescript
import { RecursiveFormFieldArray } from "openapi";

let value: RecursiveFormFieldArray = {
  type: "array",
  label: "<value>",
  itemType: {
    type: "number",
    label: "<value>",
  },
};
```
