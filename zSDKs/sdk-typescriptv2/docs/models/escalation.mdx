title: "Escalation"
---

Escalation configuration with string-encoded integer expiration

## Example Usage

```typescript
import { Escalation } from "openapi";

let value: Escalation = {
  enabled: true,
  expiration: 86400,
  fallbackApprovers: [
    "admin-1",
  ],
};
```
