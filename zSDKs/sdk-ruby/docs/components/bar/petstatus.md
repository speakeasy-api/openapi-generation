# PetStatus

Status of a pet in the bar namespace

## Example Usage

```ruby
require "openapi"

value = PetStatus::AVAILABLE
```


## Values

| Name          | Value         |
| ------------- | ------------- |
| `AVAILABLE`   | available     |
| `ADOPTED`     | adopted       |
| `PENDING`     | pending       |
| `UNAVAILABLE` | unavailable   |
