### Select Server by Index

You can override the default server globally using the `WithServerIndex` option when initializing the SDK client instance. The selected server will then be used as the default on the operations that use it. This table lists the indexes associated with the available servers:



#### Example

```go
package main

import (
	"context"
	"log"
	"openapi"
	"openapi/models/components"
	"openapi/models/operations"
)

func main() {
	s := openapi.New(
		openapi.WithServerIndex(1),
		openapi.WithSecurity(components.Security{
			Option1: &components.SecurityOption1{
				Username: "<USERNAME>",
				Password: "<PASSWORD>",
			},
		}),
		openapi.WithQueryParam1("some example query param"),
		openapi.WithDeprecatedQueryParam2("some example query param"),
	)
	request := operations.PostFileRequestBody{
		File: components.File{
			FileName: "your_file_here",
			Content:  []byte("0x8fBAEeAAE7"),
		},
	}
	ctx := context.Background()
	res, err := s.PostFile(ctx, request)
	if err != nil {
		log.Fatal(err)
	}
	if res.File != nil {
		// handle response
	}
}

```

#### Variables

Some of the server options above contain variables. If you want to set the values of those variables, the following options are provided for doing so:
 * `WithHostname string`
 * `WithPort string`

### Override Server URL Per-Client

The default server can also be overridden globally using the `WithServerURL` option when initializing the SDK client instance. For example:
```go
package main

import (
	"context"
	"log"
	"openapi"
	"openapi/models/components"
	"openapi/models/operations"
)

func main() {
	s := openapi.New(
		openapi.WithServerURL("http://localhost:35123"),
		openapi.WithSecurity(components.Security{
			Option1: &components.SecurityOption1{
				Username: "<USERNAME>",
				Password: "<PASSWORD>",
			},
		}),
		openapi.WithQueryParam1("some example query param"),
		openapi.WithDeprecatedQueryParam2("some example query param"),
	)
	request := operations.PostFileRequestBody{
		File: components.File{
			FileName: "your_file_here",
			Content:  []byte("0x8fBAEeAAE7"),
		},
	}
	ctx := context.Background()
	res, err := s.PostFile(ctx, request)
	if err != nil {
		log.Fatal(err)
	}
	if res.File != nil {
		// handle response
	}
}

```

### Override Server URL Per-Operation

The server URL can also be overridden on a per-operation basis, provided a server list was specified for the operation. For example:
```go
package main

import (
	"context"
	"log"
	"openapi"
	"openapi/models/operations"
)

func main() {
	s := openapi.New(
		openapi.WithQueryParam1("some example query param"),
		openapi.WithDeprecatedQueryParam2("some example query param"),
	)
	security := operations.ListTest1Security{
		APIKey: "<YOUR_API_KEY>",
	}

	var page int64 = 100

	var headerParam1 string = "some example header param"

	var queryParam1 *string = openapi.String("some example query param")
	ctx := context.Background()
	res, err := s.Tag1.ListTest1(ctx, security, page, headerParam1, queryParam1, operations.WithServerURL("http://localhost:35123"))
	if err != nil {
		log.Fatal(err)
	}
	if res.Object != nil {
		for {
			// handle items

			res, err = res.Next()

			if err != nil {
				// handle error
			}

			if res == nil {
				break
			}
		}

	}
}

```
