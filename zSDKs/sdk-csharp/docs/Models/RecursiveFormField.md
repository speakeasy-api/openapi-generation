# RecursiveFormField

A form field schema that can be recursive - the array type variant contains an array of RecursiveFormField items.


## Supported Types

### Text

```csharp
RecursiveFormField.CreateText(/* values here */);
```

### Number

```csharp
RecursiveFormField.CreateNumber(/* values here */);
```

### Array

```csharp
RecursiveFormField.CreateArray(/* values here */);
```
